## What is this?
A CRUD web application for personal finance tracking. Primarily a sandbox for [DawitSurithpinyo](https://github.com/DawitSurithpinyo) to learn more about fullstack (especially back-end) development, webapp security, coding structure/architecture, optimal DB management, and hopefully DevOps and cloud in the future.


## Tech stack
Front-end: React.js, Typescript

Back-end: Python, Flask

DB: MongoDB, Redis
